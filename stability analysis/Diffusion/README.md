# Diffusion B-spline stability analysis

`run_h_refinement.py` performs an isolated B-spline refinement study using
`Diffusion/Bspline_2D.py` without editing the original solver or configuration.
It evaluates

```text
n_basis = 9, 11, 13, 17, 21, 29, 37
degree  = 5
```

and keeps the collocation ratio constant:

```text
rho = N_Omega / N_free,
N_free = (n_basis - 2)(n_basis - 1).
```

The default is `rho=10`. Tuned loading and normal solver output saving are
disabled. A fixed validation seed gives the same validation set in every case.

From the repository root, run:

```text
python "stability analysis/Diffusion/run_h_refinement.py" --device gpu
```

To select another fixed density:

```text
python "stability analysis/Diffusion/run_h_refinement.py" --device gpu --rho 20
```

The first aggregate result is written to
`stability analysis/Diffusion/diffusion_h_refinement_results.npz`. Additional
runs are preserved as `diffusion_h_refinement_results_run_02.npz`,
`diffusion_h_refinement_results_run_03.npz`, and so forth, so an earlier
experiment is never overwritten.

After the refinement run finishes, create the publication-style convergence
figure with:

```text
python "stability analysis/Diffusion/plot_h_refinement.py"
```

The plotter automatically loads the most recently created refinement archive,
prints the observed rates, and saves `diffusion_h_refinement.pdf` in the same
folder. Its font sizes and 650 DPI PDF setting match the figures generated by
`Diffusion/postprocessing/plot_results.py`.

## Degree refinement

The isolated degree study fixes eight knot spans, (h=1/8), and the
collocation ratio while evaluating

```text
degree  = 2, 3, 4, 5, 6
n_basis = 10, 11, 12, 13, 14
```

Run and plot it with:

```text
python "stability analysis/Diffusion/run_p_refinement.py" --device gpu
python "stability analysis/Diffusion/plot_p_refinement.py"
```

Repeated runs receive numbered NPZ filenames and are never overwritten. The
plotter automatically reads the newest p-refinement archive and saves
`diffusion_p_refinement.pdf` with the same publication styling as the other
Diffusion figures.

## Collocation-density study

The density study fixes (n=13), (p=5), (h=1/8), the initialization
seed, and the validation set. It varies only

```text
rho = 0.5, 1, 2, 4, 8, 10, 16, 32
```

using (N_\Omega=\lceil\rho N_{\mathrm{free}}\rceil) and
(N_{\mathrm{free}}=132). Run and plot it with:

```text
python "stability analysis/Diffusion/run_rho_refinement.py" --device gpu
python "stability analysis/Diffusion/plot_rho_refinement.py"
```

The run archives are never overwritten. The plotter reads the newest density
archive and saves `diffusion_rho_refinement.pdf` using the same Diffusion
figure settings.
